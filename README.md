# Mysql_assignment1
About This Project

This repository contains my MySQL assignment on DDL (Data Definition Language) commands and SQL constraints.

As part of this assignment, I practised creating tables, modifying their structure, renaming them and deleting them using different DDL commands. I also explored how constraints are used to maintain data accuracy and establish relationships between tables.

What I Learned

Through this assignment, I got hands-on experience with the following SQL commands and concepts.
DDL Commands

CREATE – Used to create new tables in a database.

ALTER – Used to add, modify or remove columns and constraints in existing tables.

RENAME – Used to change the name of an existing table.

DROP – Used to delete tables from a database.

Constraints

I also practised using different SQL constraints:

PRIMARY KEY – To uniquely identify each record.

FOREIGN KEY – To establish relationships between tables.

NOT NULL – To make sure a column cannot be left empty.

UNIQUE – To prevent duplicate values in a column.

CHECK – To ensure that the entered values satisfy a given condition.

Tables Used

For this assignment, I worked with three tables:

Employees – Contains employee details such as ID, name, gender, age, hire date and other related information.

Departments – Stores department-related details.

Location – Stores information about different locations.

These tables are connected using primary key and foreign key constraints.
